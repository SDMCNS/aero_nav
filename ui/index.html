================================================================================ AERONAUTICAL RADIO NAVIGATION & DIGITAL AVIONICS HANDBOOK TECHNICAL PROPAGATION PHYSICS, SENSOR FUSION & FLIGHT INSTRUMENTS SPECIFICATION ================================================================================ 1. VHF OMNIDIRECTIONAL RANGE (VOR) & PHASE COMPARISON PHYSICS: - Band: VHF 108.000 to 117.975 MHz with 50 kHz spacing. - Omnidirectional reference signal (30 Hz FM on 9960 Hz subcarrier) + variable signal (30 Hz AM). - Radial = Phase difference between reference and variable: Δφ = Radial_mag = (True Bearing - Magnetic Declination) % 360° - Course Deviation Indicator (CDI): Standard 5 dots left/right, 2.0° per dot (±10° full scale). - Cone of Confusion (Zenith Null): Directly above antenna, vertical radiation drops off. Inverted cone half-angle ~40°. Within cone, CDI needles oscillate and NAV warning flag drops. 2. DISTANCE MEASURING EQUIPMENT (DME) PULSE PAIRS: - Band: UHF 960 to 1215 MHz. Interrogator transmits 12 µs pulse pairs (X channel) or 36 µs (Y channel). - Ground Transponder applies calibrated 50 µs delay and replies on paired frequency offset by ±63 MHz. - Slant Range Equation: R_slant = sqrt(D_ground_nm² + ((Alt_aircraft - Alt_station) / 6076.115)²) - High-Altitude Slant-Range Error: An aircraft directly over Shannon at FL370 reads 6.09 NM, not 0! 3. NON-DIRECTIONAL BEACONS (NDB) & AUTOMATIC DIRECTION FINDER (ADF): - Band: LF/MF 190 to 1750 kHz. Groundwave propagation following Earth curvature. - Crossed-loop directional antenna null + sense antenna circular pattern = Cardioid pattern. - Equations: Relative Bearing (RB) = (True Bearing - Aircraft Heading + 360°) % 360° Magnetic Inbound (QDM) = Aircraft Magnetic Heading + Relative Bearing Magnetic Outbound (QDR) = (QDM ± 180°) % 360° 4. INSTRUMENT LANDING SYSTEM (ILS): - Localizer (LOC): VHF 108.10 - 111.95 MHz. Carrier modulated with 90 Hz (left) and 150 Hz (right). Full scale deflection = ±2.5° (0.5° per dot). - Glide Path (GP): UHF 329.15 - 335.00 MHz. Modulated with 90 Hz (above) and 150 Hz (below). Nominal slope = 3.0°. Full scale deflection = ±0.7° (0.14° per dot). 5. ARINC 429 AVIONICS DIGITAL BUS ARCHITECTURE: - 32-bit digital word: Label (octal, bit-reversed) [1-8], SDI [9-10], Data [11-29], SSM [30-31], Parity [32]. - Label 212: VOR Bearing (BNR 0.044° resolution). - Label 037: DME Distance (BNR 0.1 NM resolution). - Label 173: Localizer Deviation (BNR DDM). - Label 174: Glideslope Deviation (BNR DDM). - Label 162: ADF Relative Bearing. - Label 030: VHF NAV Tuned Frequency.
